# คู่มือใช้งาน Stay Book ภาษาไทย

Stay Book คือระบบบันทึกผู้เข้าพักของน้ำเหนือรีสอร์ท ใช้จัดการห้องพัก การจอง เช็กอิน เช็กเอาต์ ประวัติลูกค้า และรายงานสรุป รองรับทั้งคอมพิวเตอร์ แท็บเล็ต และโทรศัพท์มือถือ

## 1. การติดตั้งและเปิดระบบครั้งแรก

### สิ่งที่ต้องมี

- Docker Desktop สำหรับ Windows/macOS หรือ Docker Engine พร้อม Compose สำหรับ Linux
- พอร์ต `8080` ว่างสำหรับเปิดเว็บไซต์

เปิด PowerShell หรือ Terminal ที่โฟลเดอร์โปรเจกต์ แล้วรัน:

```powershell
Copy-Item .env.example .env
docker compose up -d --build
```

สำหรับ Linux หรือ macOS ใช้คำสั่งคัดลอกไฟล์นี้แทน:

```bash
cp .env.example .env
docker compose up -d --build
```

รอจนคอนเทนเนอร์เริ่มทำงาน แล้วเปิด <http://localhost:8080>

บัญชีเริ่มต้นสำหรับเครื่องพัฒนา:

- อีเมล: `admin@staybook.local`
- รหัสผ่าน: `ChangeMe123!`

ควรเปลี่ยน `APP_KEY`, `DEMO_ADMIN_EMAIL` และ `DEMO_ADMIN_PASSWORD` ใน `.env` ก่อนเปิดใช้จริง หากระบบสร้างบัญชีเริ่มต้นไปแล้ว ให้สร้างบัญชีใหม่ด้วยคำสั่ง `user:create` แล้วปิดใช้งานบัญชีตัวอย่าง

## 2. เมนูหลัก

บนคอมพิวเตอร์ เมนูอยู่ด้านซ้ายของหน้าจอ ส่วนโทรศัพท์มือถืออยู่แถบด้านล่าง

1. **วันนี้** — จุดเริ่มงาน แสดงรายการเช็กอิน เช็กเอาต์ ห้องที่กำลังเข้าพัก และมัดจำที่ต้องติดตาม
2. **ผังห้อง** — ดูห้องว่างและห้องที่มีผู้เข้าพัก แยกตามโซน
3. **ตารางเข้าพัก** — ดูรายการจอง ค้นหา กรองสถานะ และเปิดมุมมองปฏิทิน
4. **ภาพรวม** — ดูรายได้ อัตราเข้าพัก จำนวนผู้เข้าพัก และกราฟสรุป
5. **ห้องพัก** — เพิ่มหรือแก้ไขข้อมูลห้อง ราคา ความจุ และการรองรับสัตว์เลี้ยง
6. **ลูกค้า** — ค้นหาและดูประวัติการเข้าพัก ยอดสะสม โน้ต และความต้องการของลูกค้า

กดปุ่ม **ค้นหา** ด้านบน หรือกด `Ctrl + K` บน Windows/Linux และ `Command + K` บน macOS เพื่อค้นหาเมนู ลูกค้า เบอร์โทร ห้อง และ Booking จากจุดเดียว

## 3. เปิดรายการจองหรือเข้าพัก

1. กด **+ เปิดรายการเข้าพัก** ที่มุมขวาบน หรือกดห้องว่างจากหน้าผังห้อง
2. กรอกชื่อลูกค้าและเบอร์โทร ระบบจะค้นหาลูกค้าเดิมจากเบอร์โทรให้อัตโนมัติ
3. เลือกวันเช็กอิน วันเช็กเอาต์ ห้องพัก และจำนวนผู้เข้าพัก
4. ระบุมัดจำ ส่วนลด เตียงเสริม หรือสัตว์เลี้ยงตามจริง
5. หากต้องการเช็กอินทันที ให้เลือก **ตรวจสอบบัตรแล้ว** และ **เช็กอินทันที**
6. ตรวจสอบราคาที่ระบบคำนวณด้านล่าง แล้วกด **บันทึก Booking**

ระบบไม่อนุญาตให้จองห้องทับซ้อนกัน และจะตรวจสอบจำนวนคนสูงสุดรวมถึงเงื่อนไขห้องที่รองรับสัตว์เลี้ยง

## 4. ค้นหาและจัดการรายการเข้าพัก

ไปที่เมนู **ตารางเข้าพัก** แล้วค้นหาด้วยชื่อลูกค้า เบอร์โทร ชื่อห้อง โซน หรือหมายเหตุ สามารถกรองสถานะเป็น:

- รอเช็กอิน
- กำลังเข้าพัก
- เช็กเอาต์แล้ว

เลือก **รายการ** เพื่อดูแบบรายการ หรือ **ปฏิทิน** เพื่อดูตามวันและเดือน จากการ์ดรายการสามารถแก้ไข เช็กอิน ต่อระยะเวลา เช็กเอาต์ แนบไฟล์ หรือลบรายการตามสิทธิ์ของผู้ใช้

## 5. เช็กอิน

1. เปิดรายการที่มีสถานะ **รอเช็กอิน**
2. ตรวจสอบข้อมูลลูกค้า ห้อง และวันเข้าพัก
3. ต้องทำเครื่องหมายยืนยันว่าตรวจสอบบัตรประชาชนแล้ว
4. กด **เช็กอิน**

หากมีผู้เข้าพักในห้องนั้นอยู่ หรือมีรายการอื่นทับซ้อน ระบบจะไม่อนุญาตให้เช็กอิน

## 6. ต่อระยะเวลาพัก

1. เปิดรายการที่ต้องการแล้วเลือก **ต่อเวลา**
2. เลือกวันเช็กเอาต์ใหม่
3. แก้ไขส่วนลดถ้าจำเป็น
4. ตรวจสอบยอดใหม่แล้วกดยืนยัน

ระบบจะตรวจสอบว่าช่วงวันที่ใหม่ไม่ชนกับรายการจองถัดไปของห้องเดียวกัน

## 7. เช็กเอาต์และตรวจห้อง

1. เปิดรายการที่มีสถานะ **กำลังเข้าพัก** แล้วเลือก **เช็กเอาต์**
2. ตรวจสอบรายการทั้ง 5 ข้อ ได้แก่ กุญแจ ความสะอาด อุปกรณ์ ความเสียหาย และมินิบาร์
3. หากพบความเสียหาย ต้องกรอกรายละเอียดในช่องหมายเหตุ
4. กดยืนยันเพื่อจบการเข้าพักและเปลี่ยนห้องกลับเป็นห้องว่าง
5. หลังเช็กเอาต์ สามารถบันทึกคะแนนและความคิดเห็นของลูกค้าได้

## 8. จัดการห้องพัก

ไปที่เมนู **ห้องพัก** แล้วกด **+ เพิ่มห้อง** เพื่อระบุ:

- ชื่อห้องและโซน
- ประเภทห้องและราคาต่อคืน
- จำนวนผู้เข้าพักพื้นฐานและจำนวนสูงสุด
- ค่าบริการคนเพิ่มต่อคืน
- ลำดับการแสดงผล
- การรองรับสัตว์เลี้ยง

การลบห้องที่มีประวัติการเข้าพักเป็นการดำเนินการสำคัญ ควรสำรองข้อมูลก่อนและตรวจสอบสิทธิ์ผู้ใช้ให้ถูกต้อง

## 9. จัดการข้อมูลลูกค้า

ในเมนู **ลูกค้า** สามารถค้นหาด้วยชื่อหรือเบอร์โทร และเรียงตามวันที่เข้าพักล่าสุด จำนวนครั้ง ยอดสะสม หรือชื่อ เลือกลูกค้าเพื่อดูประวัติทั้งหมดและแก้ไข:

- ชื่อและเบอร์โทร
- ประเภทลูกค้า
- สถานะลูกค้าประจำ
- โน้ตถาวร
- ความต้องการหรือความชอบ

## 10. รายงานและการส่งออก

ไปที่เมนู **ภาพรวม** แล้วเลือกช่วง **วันนี้**, **7 วันล่าสุด**, **เดือนนี้** หรือกำหนดวันที่เอง ระบบจะแสดงข้อมูลการจอง รายได้ อัตราเข้าพัก มัดจำ และคะแนนประเมิน

- กด **ส่งออก CSV** เพื่อดาวน์โหลดรายงานสำหรับเปิดใน Excel หรือ Google Sheets
- กด **พิมพ์** เพื่อพิมพ์หรือบันทึกเป็น PDF ผ่านหน้าต่างพิมพ์ของเบราว์เซอร์

## 11. แนบและดาวน์โหลดไฟล์

เลือกรายการเข้าพักแล้วกด **แนบไฟล์** ระบบรองรับ JPEG, PNG, WebP และ PDF ขนาดไม่เกิน 5 MB ไฟล์จะถูกเก็บนอกโฟลเดอร์สาธารณะ และดาวน์โหลดได้ผ่านผู้ใช้ที่เข้าสู่ระบบและมีสิทธิ์เท่านั้น

หลีกเลี่ยงการแนบข้อมูลส่วนบุคคลเกินความจำเป็น และกำหนดระยะเวลาจัดเก็บตามนโยบายของรีสอร์ต

## 12. สิทธิ์ผู้ใช้

- **admin** — จัดการข้อมูลและการตั้งค่าทั้งหมด
- **front_desk** — จัดการงานหน้าฟรอนต์ เช่น Booking ลูกค้า เช็กอิน เช็กเอาต์ และแบบประเมิน
- **housekeeping** — ดูผังห้อง แนบหลักฐาน และบันทึกผลตรวจห้องตามสิทธิ์ที่กำหนด

สร้างผู้ใช้ใหม่จากคอนเทนเนอร์ PHP:

```bash
docker compose exec php php bin/console user:create --name="ชื่อพนักงาน" --email="staff@example.com" --password="รหัสผ่านที่ปลอดภัย" --role=front_desk
```

ค่าของ `--role` ใช้ `admin`, `front_desk` หรือ `housekeeping`

## 13. สำรองข้อมูล

สร้างสำเนาฐานข้อมูล SQLite แบบออนไลน์ด้วยคำสั่ง:

```bash
docker compose exec php php bin/console db:backup
```

ระบบเก็บสำเนาล่าสุดตามจำนวน `BACKUP_KEEP` ใน `.env` ควรสำรอง Docker volume ของไฟล์แนบควบคู่กับฐานข้อมูลเสมอ เพราะฐานข้อมูลและไฟล์แนบอยู่คนละ volume

## 14. ปิด เปิดใหม่ และดูบันทึกระบบ

```bash
docker compose down             # ปิดระบบ
docker compose up -d            # เปิดระบบอีกครั้ง
docker compose logs -f          # ดูบันทึกการทำงาน
docker compose ps               # ดูสถานะคอนเทนเนอร์
```

คำสั่ง `docker compose down` จะไม่ลบข้อมูลใน named volumes อย่าเพิ่ม `-v` หากไม่ได้ตั้งใจลบข้อมูลถาวร

## 15. แก้ปัญหาเบื้องต้น

- **เปิดเว็บไม่ได้** — ตรวจสอบว่า Docker Desktop ทำงานอยู่ แล้วรัน `docker compose ps` และ `docker compose logs`
- **คอนเทนเนอร์ `php` restart ตลอดหรือ Nginx ยังไม่เริ่ม** — รัน `docker compose logs php`; เวอร์ชันนี้ตั้ง PHP-FPM ให้เขียน log ลง `storage/logs` ซึ่งผู้ใช้ `www-data` เขียนได้แล้ว หากใช้ image เก่าให้รัน `docker compose up -d --build` อีกครั้ง
- **พอร์ต 8080 ถูกใช้งาน** — เปลี่ยน `APP_PORT` ใน `.env` เช่น `APP_PORT=8088` แล้วเปิดด้วยพอร์ตใหม่
- **เข้าสู่ระบบไม่ได้** — ตรวจสอบอีเมล/รหัสผ่าน หากลองผิดครบ 5 ครั้ง ต้องรอ 15 นาที
- **ไม่พบไฟล์ CSS/JavaScript** — รัน `docker compose up -d --build` เพื่อสร้าง assets ใหม่
- **ฐานข้อมูลถูกล็อก** — ตรวจสอบสิทธิ์เขียนของ volume และโฟลเดอร์ `storage/database`; ระบบเปิด WAL และกำหนด busy timeout ไว้แล้ว
- **PostgreSQL/Supabase เชื่อมต่อไม่ได้** — ตรวจสอบ host, port, รหัสผ่าน, TLS และค่า prepared statements ตามชนิด pooler
