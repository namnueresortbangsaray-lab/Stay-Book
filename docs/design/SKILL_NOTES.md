# ui-ux-pro-max skill — notes

1. **Install and version:** v2.15.0 (MIT, nextlevelbuilder), installed for the user at `~/.claude/skills/ui-ux-pro-max`, not inside this repo. It contains `SKILL.md`, `references/` (quick-reference.md with 10 rule categories, pro-rules.md with the pre-delivery checklist), `data/` (CSV databases) and `scripts/` (Python search and design-system generator).
2. **Scripts reviewed before use:** `search.py`, `core.py`, `design_system.py`, `reasoning_contract.py` and `validate_data.py` import only the Python standard library. They read the skill's own `data/*.csv`, have no network or subprocess calls, and write files only with `--persist` (into `--output-dir`). Safe to run.
3. **Prerequisite missing:** Python 3 is not installed on this machine, so `search.py` and `--design-system` cannot run. Nothing was installed. The same data was looked up by reading the CSVs directly, and the blocker is recorded in `CLAUDE.md`.
4. **UX guidelines:** 119 rules in `ux-guidelines.csv` and the priority-ordered `quick-reference.md` (accessibility → touch → performance → style → layout → typography/colour → animation → forms → navigation → charts). These drive `SKILL_AUDIT.md`.
5. **Stack guidance:** `data/stacks/html-tailwind.csv` (59 Tailwind rules) is the closest match for Razor + Tailwind 3 + vanilla JS. Used for focus, disabled, loading, touch-target, truncation and z-index checks.
6. **Product reasoning:** the "Hotel/Hospitality" rows (products, ui-reasoning, colors) target a guest-facing hotel website: Liquid Glass, hero layouts, gold accent. For a staff PMS the closer rows are "Analytics Dashboard" / "Data-Dense Dashboard", "Productivity Tool" (Flat Design) and "Minimalism & Swiss Style". The comparison is in `SKILL_AUDIT.md`.
7. **Overrides:** project constraints win over the skill. The palette stays blue/white with Light/Dark/System; there are no Google Fonts or CDN (the skill's font rows all use Google Fonts URLs); CSP stays intact; typography is Thai-first. Glass, hero and gold suggestions are rejected for a back-office tool.
8. **Pre-delivery checklist:** `references/pro-rules.md` (process, visual quality, interaction, light/dark, layout, accessibility). It is written for native apps, so web-relevant items are applied and the rest are marked not applicable.
9. **How it is used here:** audit real screens and code against §1–§10, rate each finding critical/major/minor with its rule ID, and fix in this order: tokens → shell → shared components → pages.
10. **Not used:** sample content, brand names, GSAP presets, Google Fonts imports, the `design-system/` persistence folder (it would duplicate `docs/DESIGN_SYSTEM.md`).
